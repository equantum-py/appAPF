# E-00 — Repositorio y CI
Responsable: agente implementador; aprobación de cierre: Derlis.
Objetivo: checkout reproducible, frontend compilable, paquete Python importable y CI verificable.
HARD: P-01 y P-04 COMPLETED según GATE-00 aprobado. CONTRACT: sin contratos API en esta entrega. EXTERNAL: npm/PyPI y GitHub Actions disponibles.
Alcance: estructura modular, página inicial que declara estado de desarrollo, dependencias fijadas, lockfiles, lint, tipos, build y validación documental. No API de salud: corresponde E-01. No autenticación, DB, videos, PWA integrada ni funciones de negocio.
Archivos: apps/web, services/api, packages/config, packages/contracts, infra, .github/workflows/ci.yml, docs/evidence y estado.
Migraciones/endpoints/permisos de negocio: N/A porque E-00 no implementa datos ni API. CI con contents:read y sin secretos.
Pruebas: npm ci desde lockfile; ESLint; tsc; Next build; uv sync --locked; Ruff; pytest para importación de estructura; validación documental; git diff --check. CI debe ejecutar estas mismas comprobaciones en checkout limpio y publicar reporte ligado a github.sha.
Aceptación: todas las pruebas pasan y corrida GitHub Actions del commit exacto termina success. Si Actions está bloqueado registrar NOT_RUN y mantener IN_REVIEW/BLOCKED; no declarar CI funcional sin corrida.
Evidencias: logs locales y corrida CI con commit/entorno/fecha. Riesgo: conectividad o límites Actions; no desactivar controles para superarlo.
Reversión: revertir commit; no hay datos o infraestructura creados. Cierre: DoD y aprobación humana del commit probado.
